# Fotos del sitio

Sube aquí las fotos con **exactamente** estos nombres (JPG, idealmente 1600 px de ancho o menos).
En cuanto un archivo existe, aparece en el sitio; si falta, se muestra el diseño de respaldo.

| Archivo | Dónde aparece |
|---|---|
| `zonas/binaes.jpg` | Tarjeta Zona Bitcoin BINAES |
| `zonas/aeropuerto.jpg` | Tarjeta Zona Bitcoin Aeropuerto |
| `zonas/panchimalco.jpg` | Tarjeta Zona Bitcoin Panchimalco |
| `zonas/apopa.jpg` | Tarjeta Zona Bitcoin Apopa |
| `historico/palacio.jpg` | Bitcoin Histórico · Palacio Nacional |
| `historico/plaza.jpg` | Bitcoin Histórico · Plaza Gerardo Barrios |
| `historico/2025-1.jpg` … `2025-6.jpg` | Galería “Así se vivió 2025” (se muestra cuando hay al menos una) |
| `cubo-1.jpg` | CUBO+ foto grande (grupo) |
| `cubo-2.jpg` | CUBO+ foto pequeña 1 y fondo de la portada |
| `cubo-3.jpg` | CUBO+ foto pequeña 2 |
| `egresados/<nombre-apellido>.jpg` | Foto de cada egresado (ej. `fhernanda-elias.jpg`, `rodrigo-aguilera.jpg`, `moises-iglesias.jpg`, `jonathan-ramos.jpg`, `rodrigo-bonilla.jpg`, `naomi-iglesias.jpg`) |

Cómo subir: en GitHub abre la carpeta `img/` → **Add file → Upload files** → arrastra las fotos → **Commit changes**.
